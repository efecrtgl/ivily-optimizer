## Ivily Optimizer 0.2.0

Ivily Optimizer'ın ilk yayımlanan sürümü: Windows için yerel, gizlilik odaklı ve şeffaf bir sistem zekâsı, depolama analizi ve bakım uygulaması.

### Öne çıkanlar

- **Ivily Zekâsı:** diskler, depolama içgörüleri, temizlik, Windows olay günlüğü, başlangıç öğeleri, karantina ve güncellemelerden kanıta dayalı öneriler. Ölçülen veri ile "Ivily yorumu" her zaman ayrı gösterilir.
- **Sistem Geçmişi:** Windows Sistem/Uygulama olay günlükleri için kategoriler, zaman çizelgesi, tekrarlayan sorunlar, olay bağlamı ve TXT/CSV/JSON rapor.
- **Depolama zekâsı:** disk analizi, treemap, kullanıcı klasörleri, uygulama depolaması, geçici/önbellek klasörleri, küçük dosya yoğunluğu, büyüme takibi, anlık görüntü karşılaştırma.
- **Dosya Yönetimi:** gelişmiş gezgin, meta veri ve dijital imza, SHA-256 + BLAKE3 özet, klasör karşılaştırma, CSV envanter, büyük/eski/yinelenen dosyalar, boş klasörler.
- **Güvenli temizlik:** risk sınıfları, dosya düzeyinde önizleme, onay, iptal, gerçek sonuç raporu, karantina modu.
- **Sistem yönetimi:** imza doğrulamalı başlangıç yönetimi, süreç ağacı ve ayrıntıları, servis bağımlılıkları, zamanlanmış görev geçmişi, güç planları, ağ tanılama.
- **İzlenebilirlik:** önceki/yeni durumu, onayı ve geri alma durumunu kaydeden işlem geçmişi; arka uçta doğrulanan geri alma.
- **Yeni arayüz:** tek renkli cam tasarım sistemi, sıfırdan modüler pano, yenilenen kedi işareti, koyu/açık/sistem tema.
- **Güncellemeler:** GitHub Releases üzerinden; yalnızca uygulamaya gömülü anahtarla doğrulanan imzalı paketler kurulur.

Tüm değişiklikler: [CHANGELOG.md](https://github.com/efecrtgl/ivily-optimizer/blob/main/CHANGELOG.md)

### İndirme

| Dosya | Açıklama |
|---|---|
| `Ivily.Optimizer_0.2.0_x64-setup.exe` | Windows yükleyicisi (önerilen). Yönetici hakkı gerektirmez, yalnızca kullanıcı hesabına kurulur. |
| `Ivily.Optimizer_0.2.0_x64_tasinabilir.zip` | Kurulumsuz taşınabilir sürüm. Uygulama içinden otomatik güncellenmez. |
| `Ivily.Optimizer_0.2.0_x64-setup.exe.sig` | Uygulama içi güncelleyicinin doğruladığı minisign imzası. |
| `latest.json` | Uygulama içi güncelleyici bildirimi. |
| `SHA256SUMS.txt` | Elle bütünlük denetimi için SHA-256 özetleri. |

Gereksinimler: Windows 10 (1803+) veya Windows 11, 64 bit; Microsoft Edge WebView2 Çalışma Zamanı (Windows 11'de hazır gelir, yoksa yükleyici kurar).

### Bilinen sorunlar

- Yükleyici Authenticode kod imzalama sertifikasıyla imzalı değildir; Windows SmartScreen "Windows bilgisayarınızı korudu" uyarısı gösterebilir ("Ek bilgi > Yine de çalıştır").
- Açılış performansı kayıtları Windows'ta yönetici hakkı gerektirir; standart kullanıcıda gösterilmez.
- Servis, görev, başlangıç ve güç planı değişiklikleri ile bunların geri alınması birim testlidir; geliştirme sırasında gerçek sistemde çalıştırılmamıştır.
- Artımlı disk taraması yoktur; her tarama tam yapılır.

### Derleme bilgisi

Yerel Windows derlemesi (Rust stable, Tauri 2, NSIS). 129 Rust testi ve arayüz tür denetimi başarılı.
